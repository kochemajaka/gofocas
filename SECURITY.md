# Security Policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, use [GitHub's private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) or email the maintainers directly.

Include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact

We aim to respond within 5 business days and to publish a fix within 30 days of confirmation.
